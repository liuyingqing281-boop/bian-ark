# 彼岸 · 线上纪念馆

> 思念有处安放 —— 为想念的人建一座安静的线上纪念馆

## 👉 在线使用

**[https://bianmuyuan.cn](https://bianmuyuan.cn)**

打开即用：进入后注册/登录（手机或邮箱验证码，登录即注册）→ 为 TA 建一座纪念馆 → 记录故事、留言、献花点灯。

## 这是什么

一个线上纪念产品：给逝去的亲人、宠物、想念的人建一座纪念馆，把 TA 的照片、故事、你们之间的回忆放在这里；想 TA 的时候来说说话、献一束花、点一盏灯。

- 🏛️ **建馆向导**：3 步建馆（TA 是谁 → TA 的故事 → 确认生成），建馆即带记忆档案
- 📖 **记忆档案**：5 个分区记录 TA 是怎样的人、你们的故事、TA 喜欢什么
- 💬 **想念**：留言 / 悄悄话 / 悼文；基于记忆档案的缅怀对话（明确边界：不是 TA 本人）
- 🕯️ **祭奠**：鲜花 / 点灯 / 清香基础祭品免费；付费祭品一口价明码标价
- 🌳 **公共墓园**：开放的纪念馆广场
- 👨‍👩‍👧 **亲友共同纪念**：邀请亲友协作维护同一座馆

## 设计原则

纪念馆是主体，AI 不是主角；商业化克制——无虚拟币、无打榜、无自动续费；庄重、安静、有温度。

## 技术栈

Next.js 16 (App Router, Turbopack) · TypeScript · SQLite (better-sqlite3, WAL) · PM2 · Nginx · 阿里云轻量服务器
