# 项目完成规划（单人开发模式）

> 2026-08-19 起生效 ｜ 原三人分工作废（刘洋、颜新航因工作调动离开）
> 模式：**刘贻清（决策+账号操作+运营） + ZCode（全部代码实现）**，小步发布
> 产品定位不变：见 `PRD-彼岸3.0.md`（核心闭环 = 建馆 → 进群 → 祭奠，已上线 https://bianmuyuan.cn）

## 单人模式的三个原则

1. **验证优先于功能**：核心闭环已在公网运行，当前里程碑是「真实用户验证」，不是继续堆功能
2. **小步发布**：每次改动一条命令上线（服务器 `bash deploy/deploy.sh`），不攒大版本
3. **时间分工**：刘贻清只做机器做不了的事（账号/备案/拉用户/拍板）；其余全部交给 ZCode
