# 彼岸纪念馆：让思念有处安放，让纪念真实、庄重、透明

有些人，离开了很久，我们仍然会在某个普通的日子想起他们。

也许我们正在异地工作，身在海外，或者因为突发情况无法回到故乡。想念不会因为距离消失，纪念也不应该只发生在清明这一天。对很多人来说，一个可以随时回去看看的纪念空间，已经成为日常生活里安静而重要的一部分。

## 线上纪念，不只是把扫墓搬到网上

公开调研中，有人连续多年在线上祭扫、写下悼文；有人每天打开纪念馆，和已故的伴侣说说话；也有人因为远在外地，选择在网上为家人建一座馆。

这些真实经历说明，线上祭奠的核心并不是“完成一次操作”，而是让人拥有一个可以持续表达思念的地方：写一段话，上传一张照片，点一盏灯，或者只是安静地坐一会儿。

彼岸纪念馆因此把产品定位为：**为无法到场的怀念者，提供真实、庄重、透明的线上纪念馆。**

## 彼岸想解决的三件事

第一，让纪念随时发生。

纪念馆不是一年一次的节日页面，而是可以长期保存生平、照片、视频和悼文的私人空间。家人想念时，可以随时回来留言、献花、点灯，也可以留下只对馆主可见的“悄悄话”。

第二，让亲友能够一起纪念。

一份思念常常属于一个家庭。彼岸支持通过链接邀请亲友参与留言和祭扫，也为未来的家族祠堂、族谱和多人合馆预留空间，让不同地方的家人可以共同保存一段家族记忆。

第三，让线上纪念值得信任。

这个行业曾出现过冒名建馆、充值陷阱、虚拟币、打榜和节日涨价等问题。彼岸从产品底层排除这些做法：建馆需要实名和凭证审核，内容与权限有清晰边界，用户名默认脱敏，价格使用人民币明码标价，不设置虚拟币、排行榜和默认自动续费。

## 一座馆，应该如何被认真对待

创建纪念馆不是简单填写一张表。彼岸的建馆流程包括逝者信息、建馆人实名和必要凭证提交，系统审核与人工审核结合，避免把仍在世的人错误地放入纪念空间。

纪念馆上线后，馆主可以整理生平、上传相册、撰写悼文，并设置公开、仅链接或私密访问。访客可以浏览公开内容，但留言和祭扫需要登录；所有公开展示的用户名称都会进行脱敏处理。

如果有人发现冒名建馆、隐私泄露或不当内容，可以直接举报。涉及冒名的馆会先进入复核状态，再进行后续处理。我们希望，平台的每一次处理都留下记录，也给相关当事人清楚的申诉路径。

## 不用复杂消费，也能完成一场祭奠

基础纪念功能免费提供，包括建馆、留言、悼文、基础相册、分享，以及鲜花、蜡烛、清香等基础祭品。

需要扩展空间时，彼岸采用简单的一口价：高级主题、相册扩容和其他增值服务分别标明价格；年卡建议定价为 88 元/年，是否续费由用户主动选择，默认不自动续费。未续费时，已经创建的内容不会被删除。

我们不希望用户在悲伤时被复杂的消费机制推着走。价格应该看得懂，选择应该来得及，退款入口应该找得到。

## 给无法回家的人，一个可以回去的地方

彼岸纪念馆首先服务那些无法到场的人：异地工作的子女、身在海外的家人、行动不便的长辈，以及因为突发情况无法参加告别的人。

但我们相信，线上纪念并不意味着取代现实中的告别。它更像是一座延伸出来的空间：当你暂时不能回到墓园，可以先在这里完成一次郑重的表达；当亲友分散在各地，也可以在这里共同留下记忆。

未来，彼岸还会逐步完善家族祠堂、纪念日提醒、适老模式和对话语音等能力。所有新增功能都要服从同一个标准：服务真实的纪念需求，不制造喧闹，不消费悲伤。

## 彼岸，思念有处安放

我们做的不是一个热闹的平台，也不是一套让人不断充值的祭祀商品。

我们想做的是一座安静、可靠、可以长期保存的线上纪念馆：让不能到场的人仍然能够表达，让愿意共同纪念的家人彼此看见，让每一份思念都被认真对待。

**彼岸纪念馆，思念有处安放。**
