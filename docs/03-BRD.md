## 1. 商业目标与愿景

**愿景**：做"监管规范化时代"的第一个标杆线上纪念馆——真实、庄重、透明（承接 MRD §9 定位声明：为无法到场的怀念者提供一个真实、庄重、透明的线上纪念空间）。

**三年商业目标**（均可回溯至采集证据）：
1. **Y1（至 2027 清明后）**：跑通"免费建馆 + 透明付费"模型，建立零乱象合规记录（对应 MR-04/05/11，监管出清窗口红利，MRD §2/§7）。
2. **Y2**：沉淀家族关系链资产（MR-03），上线代祭扫撮合（MR-10），验证 B 端代建（MRD §10-2）。
3. **Y3**：进入 2030 年"用户超 1 亿"预测曲线（样本27）的早期轨道，成为"合规+透明+庄重+全年运营"四要素定位（MRD §6 空位）的默认选项。

**资源现状假设**：当前为单人开发模式（项目现状，非调研数据）；开发成本参照"同类 APP 约 6 万元含维护"（附录A）。

## 2. 商业模式设计（回答 MRD 决策 1）

**模式选择：免费建馆 + 人民币一口价增值 + 可选年卡（禁用虚拟币/打榜/默认续费）**

| 层 | 内容 | 定价 [建议] | 锚定证据 |
|---|---|---|---|
| 免费层 | 实名建馆（1 馆）、留言/悼文、基础祭品（鲜花/蜡烛/清香）、基础相册、链接分享 | 0 元 | 官方公益平台与竞品均免费建馆（附录B）；获客基准已被行业抬到 0 元 |
| 单点增值 | 高级纪念馆装饰（主题/背景/音乐）、纪念相册扩容、单人悼念空间升级 | 一口价 9.9 / 19.9 / 39.9 / 99 元（人民币直付） | 祭品实测定价 1–48 元带（附录B）；被媒体点名的"礼包 199.9 / 豪华馆 398"（S8）作为反面上限参照，本产品显著低于批评水位 |
| 年卡"彼岸年卡" | 全部增值 + 家族祠堂基础位 + 大容量相册视频 | 88 元/年，**开关式订阅、默认不自动续费** | 旧平台会员带 20 元/月（240/年）–268 元/年（附录B）；88 元定位其 1/3 水位，放大"透明低价"差异（MR-05） |
| 家族祠堂扩容 | 多逝者聚合、族谱树、多管理员协作 | 99 元/次扩容 [建议] | "家谱 200 元/姓氏"为竞品锚（附录B） |
| V2：代祭扫撮合 | 见 §5 | 服务方定价 35–260 元带，平台抽佣 15% [假设] | 官方代祭 35–260 元基准（附录B） |
| V2：B 端代建 | 殡仪馆/公墓官方馆代建与运维 | 项目制报价 | 福寿云路径参照（附录C） |

**反面清单固化（不可触碰）**：虚拟币/云币体系、充值礼包、孝爱值/香火排行榜、默认自动续费、给活人建馆、拉下线返佣——全部为 MRD §5 反面清单 + 附录B 乱象证据。

## 3. 财务模型（粗粒度，全部假设透明）

### 3.1 首年收入情景（MVP 上线至首个清明周期）

公式：收入 = 注册用户 × 付费率 × ARPU

| 情景 | 注册用户 | 付费率 | ARPU | 年收入 |
|---|---|---|---|---|
| 保守 | 2 万 | 2% | 30 元 | 1.2 万元 |
| 基准 | 5 万 | 5% | 45 元 | 11.25 万元 |
| 乐观 | 10 万 | 8% | 60 元 | 48 万元 |

- 注册用户量级 [假设]：参照心纪奠 10 万+ 注册（附录A）为行业中型平台水平；获客依赖清明脉冲与分享裂变（MRD §9），冷启动无投放预算假设。
- 付费率/ARPU [假设]：MRD 已指出"65% 愿尝试 ≠ 愿付费"（附录A），故付费率取低档；ARPU 混合单点与年卡（§2 定价带加权）。
- **诚实结论**：C 端订阅首年是十万级以内收入，不是利润引擎；首年价值在**信任资产与用户资产**（北极星指标见 §7）。MRD §3.2 的 3–53.6 亿是 2030 全市场情景，非本公司预测。

### 3.2 成本结构

| 项 | 量级 | 性质 |
|---|---|---|
| 开发 | 约 6 万元（含维护） | 采集参照（附录A） |
| 合规基座 | ICP 备案、企业主体、实名认证接口、行业标准符合 | 金额 [假设：万元级]；为发布前置（§6） |
| 服务器/带宽 | 随用户量线性 | [假设] |
| 运营 | 清明/中元/冬至内容运营，单人+AI 辅助 | 项目现状假设 |

**盈亏平衡判断** [假设推演]：首年必亏（投入 > C 端收入）；收入兑现在 Y2–Y3（家族祠堂复购 + 代祭抽佣 + B 端项目制）。商业可行性依赖 §5 的 V2 组合，而非 C 端订阅单腿。

## 4. 市场进入路径（回答 MRD 决策 2）

**C 端先行，B 端延后至 Y2**：

- 为什么不先做 B 端：福寿云已覆盖 17 省 30+ 城（附录C），官方平台有 1576 个口径在运行（附录A）——公信力与渠道正面竞争无胜算；且 B 端决策周期长。
- 为什么 C 端可行：MRD §6 定位空位（合规+透明+庄重+全年运营四要素无人在位）在 C 端体验层；单人团队可交付。
- C 端立足后 B 端反哺：以"零乱象记录 + 真实用户"作为与地方殡仪馆/公墓合作的谈判资产（对标福寿云的代建逻辑，附录C）。

**节奏锚点（倒排至 2027 清明）**：2026-09–12 MVP 与合规基座 → 2027-01 内测/明星馆试点 → 2027-02 付费上线 → **2027-04 清明大考**（附录A：清明是全年最大脉冲，首日人次为次日近 3 倍）→ 2027 中元节验证日常留存。

## 5. 两项范围决策

### 5.1 代祭扫（MRD 决策 3）：不做自营，V2 做撮合

- 理由：骗局高发信任成本高（样本12、20）；季节性极强（样本16"平时没什么生意"）；与"庄重透明"品牌自营风险大。
- V2 设计 [建议]：平台撮合 + **履约凭证标准化**（现场照片九宫格/直播回放/坐标打卡），定价锚定官方 35–260 元带（附录B），透明抽佣——把 MRD §8 的信任缺口转化为产品机会（MR-10）。

### 5.2 品牌决策（MRD 决策 4）：建议"保留彼岸 + 全称区隔"，需用户拍板

| 选项 | 内容 | 评估 |
|---|---|---|
| A. 更名 | 彻底避开"彼岸思念"（S5 点名平台） | 沉没成本最高（产品已以"彼岸"开发）；但零混淆风险 |
| **B. 保留+区隔（推荐）** | 全称固定"彼岸纪念馆"，注册商标，视觉/文案与"彼岸思念"强区隔，SEO 占位"彼岸纪念馆/彼岸网上祭扫" | 成本低；负面联想集中在"思念"后缀+云币模式，可区隔；残余风险：搜索场景仍有部分混淆 |
| C. 保留原名不动 | 维持"彼岸"裸品牌 | 风险最高，不推荐 |

**默认执行 B**；若用户倾向更名（选项 A），请在 PRD 启动前提出，PRD 将按新名输出。

## 6. 合规与风险（回答 MRD 决策 5）

**合规基座（发布前置，全部对应 MR-11/附录C）**：
1. 企业主体 + ICP 备案（涉支付需相应许可，S7 专家口径）
2. 建馆实名认证 + 亲属关系/死亡凭证审核流程（《网络祭祀要求》硬要求，2025 标准）
3. 用户协议、隐私政策、明码标价页、投诉与举报通道（S7 协会三维度）
4. 对接行业自律：备案登记、年度检测准备（S7）

**风险登记表**：

| 风险 | 概率/影响 | 应对 |
|---|---|---|
| 自身出现"活人被建馆"事故 | 低/致命（样本13 前车之鉴） | 审核 SLO：机审即时+人工 24h；冒名举报通道+先下架后申诉 |
| 监管标准再加码 | 中/中 | 合规基座冗余设计（§6 前置四项已覆盖已知要求） |
| 付费转化不及预期 | 高/中 | §3 已按低付费率规划；首年 KPI 不背收入（§7） |
| 巨头/官方免费挤压 | 中/中 | 差异化在体验与全年运营，不拼公信力（MRD §6） |
| 品牌混淆（"彼岸思念"） | 中/中 | §5.2 选项 B 组合动作 |
| 清明脉冲服务器压力 | 中/低 | 提前压测（首日人次为数倍于平日，附录A） |

## 7. KPI 体系（回答 MRD 决策 6）

**北极星指标：WAR（Weekly Active Remembrance，每周活跃纪念行为数）**= 每周发生留言/悼文/祭扫/上传/分享的用户行为总量。
理由：留存证据全部指向高频使用（样本02"每天"、样本04"九年"、样本09"悄悄话"），注册量与清明峰值均会失真（附录A 人次逐日回落）。

| 层 | 指标 | Y1 目标 [假设] |
|---|---|---|
| 获客 | 新建馆数、明星馆引流占比、亲友分享带来的注册占比 | 首清明前 1 万馆 |
| 激活 | 建馆后 7 日内完成首次祭扫/留言率 | ≥ 60% |
| 留存 | 30 日 WAR 留存、悼文书写率 | 持续观测建立基线 |
| 商业 | 付费转化率、年卡续费率（开关式续费，真实意愿） | 3%–5% |
| **红线（一票否决）** | 活人建馆事故 0、监管点名 0、客诉 24h 响应率 100%、自动扣费投诉 0 | 硬指标 |
