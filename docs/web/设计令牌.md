# 彼岸 · 设计令牌（Design Tokens）

> 单一事实来源（SSOT）：从 `prototype/shared/ui.css` 抽出的「熔火/余烬」视觉语言令牌，**移动端与 PC 端开发共用**。
> 使用规则：代码中不得写死色值/圆角/阴影，一律引用令牌；新增视觉元素必须先在此登记令牌再使用。
> 关联文档：`docs/web/01-PC前端设计文档.md` §二、`docs/前端具体设计流程.md` §1.3（原则层）。

---

## 一、色彩令牌

### 1.1 基础色板

| 令牌 | CSS 变量 | 色值 | 用途 | 限制 |
|---|---|---|---|---|
| `color.bg` | `--bg` | `#070302` | 全局页面底色 | 不用纯黑 `#000` |
| `color.bg-soft` | `--bg-soft` | `#120705` | 次级底色、深色弹层衬底 | — |
| `color.brand` | `--ember` | `#FF7A2F` | 主色 · 熔橙：主 CTA、供奉动作、当前态标识、Tab 下划线 | 大面积铺底仅限渐变按钮/品牌块 |
| `color.brand-soft` | `--ember-soft` | `#FFB35C` | 点缀 · 烛金：强调文字、年份、链接、图标点缀、焦点环 | 不做背景填充 |
| `color.brand-deep` | `--ember-deep` | `#B43A0E` | 渐变收尾色、品牌块暗部 | 仅配渐变使用 |
| `color.ok` | `--ok` | `#7FB069` | 苔绿：「免费」标、保存/供奉成功 | — |
| `color.danger` | `--danger` | `#E0604F` | 余烬红：错误、删除等破坏性操作 | 不用正红；删除必经二次确认 |

### 1.2 文字色（三级透明度体系）

| 令牌 | CSS 变量 | 值 | 用途 |
|---|---|---|---|
| `color.text` | `--text` | `#FFF6EC` | 一级文字：标题、正文 |
| `color.text-2` | `--text-2` | `rgba(255,246,236,.60)` | 二级文字：说明、列表正文 |
| `color.text-3` | `--text-3` | `rgba(255,246,236,.38)` | 三级弱文字：时间、占位、辅助提示 |

> 规则：文字色只允许这三档，禁止新增灰色；浅色底场景（不存在于当前主题）需先评审。

### 1.3 表面与描边（玻璃卡片体系）

| `surface.card-border` | `--card-border` | `rgba(255,255,255,.09)` | 卡片细边（恒 1px） |
| `surface.divider` | — | `rgba(255,255,255,.07~.08)` | 分割线、列表分隔 |

### 1.4 品牌渐变

| 令牌 | 值 | 用途 |
|---|---|---|
| `gradient.brand` | `linear-gradient(135deg,#FF8A3D,#F45D12 55%,#D9480F)` | 主按钮 |
| `gradient.brand-block` | `linear-gradient(135deg,#FF8A3D,#B43A0E)` | 品牌块/头像底 |
| `gradient.orb` | `radial-gradient(circle at 38% 32%,#FFE6C4,#FFB35C 30%,#F45D12 62%,#8A2B08)` | 发光球体（对话页核心视觉） |
| `gradient.flame` | `linear-gradient(to top,#F45D12,#FFB35C 60%,#FFE6C4)` | 烛火 |
| `gradient.page-ambient` | 顶部 `rgba(255,106,32,.18~.28)` + 底部 `rgba(180,58,14,.14~.22)` 径向渐变 | 页面氛围，**仅顶部/底部各一处** |

### 1.5 辉光（发光阴影，克制使用）

| 令牌 | 值 | 允许出现的位置 |
|---|---|---|
| `glow.brand` | `0 0 24px rgba(244,93,18,.45)` | 品牌块 |
| `glow.portrait` | `0 0 44px rgba(255,122,47,.55), 0 0 100px rgba(244,93,18,.3)` | Hero/弹层中的 TA 照片 |
| `glow.orb` | `0 0 60px rgba(255,122,47,.75), 0 0 160px rgba(244,93,18,.5), inset 0 -18px 40px rgba(120,30,5,.6)` | 发光球体 |
| `glow.flame` | `0 0 12px rgba(255,150,60,.9), 0 0 32px rgba(244,93,18,.5)` | 烛火 |
| `glow.cta` | `0 8px 28px rgba(244,93,18,.45), inset 0 1px 0 rgba(255,255,255,.35)` | 主按钮 |

> **红线：辉光仅限上表五处令牌场景，普通内容卡片、列表项、输入框一律禁用发光。**

## 五、动效令牌

| 令牌 | 值 | 用途 |
|---|---|---|
| `motion.base` | `200–300ms ease-out` | 转场、hover、弹层 |
| `motion.panel` | `250ms ease-out` | PC 侧板滑入滑出 |
| `motion.hover` | `150ms ease-out` | PC 悬停态 |
| `motion.tribute` | `≤1.2s` | 供奉动效上限，无金币/连击/音效轰炸 |
| `anim.orb-breathe` | `4.5s ease-in-out infinite`（scale 1→1.045 + brightness 1→1.12） | 发光球体呼吸 |
| `anim.flame-flicker` | `1.15s ease-in-out infinite`（scaleY/rotate 微摆动） | 烛火摇曳 |
| `anim.typing` | `1s ease-in-out infinite`（opacity .25→1） | 对话三点呼吸 |

> 禁止弹跳/弹性过冲；音效默认关闭。

## 八、变更流程

1. 任何视觉调整先改本文件令牌 → 再改 `shared/ui.css` → 最后改页面；禁止反向操作。
2. 新增令牌需注明：色值/值、用途、限制、出现场景。
3. 文案与商业化红线不在本文件范围，见 `docs/前端具体设计流程.md` §三。
