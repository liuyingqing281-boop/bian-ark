# 彼岸 · PC 端三档断点走查清单（验收用）

> 对象：`prototype/pc.html` 改造验收；依据：`docs/web/01-PC前端设计文档.md` §三/§八、`docs/web/设计令牌.md`。
> 用法：每档断点下用浏览器开发者工具设定视口宽度（1440 / 1280 / 1024），逐项截图核对并勾选；任一 ❌ 即打回，修复后重走该档全量。
> 截图命名：`pc-{breakpoint}-{序号}.png`（如 `pc-1440-03.png`），归档到 `docs/web/walkthrough/`。

## 〇、全断点通用项（每档都查）

- [ ] G01 页面底色为深黑 `#070302`，氛围渐变仅顶部/底部各一处，无第三处辉光污染源
- [ ] G02 全站无浅色/白色页面或卡片块（玻璃卡片为白 5% 底 + 细边）
- [ ] G03 熔橙 `#FF7A2F` 仅出现在：主 CTA、供奉/点灯、Tab 下划线、宫格价格外的当前态；一屏 ≤2 处大面积使用
- [ ] G04 辉光仅三处：Hero TA 照片、左导航品牌块、供桌顶部氛围；普通内容卡片无发光
- [ ] G05 标题为衬线体（名字/区块标题/年份），正文无衬线；行高 1.6
- [x] G06 键盘 Tab 走查：焦点环（2px 烛金外描边）全程可见，顺序合理
- [x] G07 Esc 可收起对话侧板；身份说明弹层 Esc **不可**关闭
- [x] G08 所有可点元素有 hover 态（背景白 4% 或透明度 85%，150ms）
- [ ] G09 文案红线：无「AI 聊天/数字人/复活逝者/充值/虚拟币/打榜」字样
- [ ] G10 昵称全为打码格式（李** / 用户A），无完整真实姓名

## 一、1440px（宽屏 · 完整布局档）

### 布局框架
- [ ] A01 左导航宽 224px 固定，滚动主区时导航不动
- [ ] A02 主内容容器 `max-width: 1120px` 居中，左右留白对称
- [ ] A03 左导航一级入口**只有 3 个**：纪念馆（当前）/ 发现（置灰 + 「后续」标）/ 我的；无想念/祭奠/记忆档案/亲友入口
- [ ] A04 底部用户卡：头像 + 打码昵称「林**」+ 「守护 128 天」+ 设置图标
- [ ] A05 主区为 12 列网格：左内容 8 列（TA 的人生、祭奠），右辅助栏 4 列（留下你的话、最近的纪念、记忆档案摘要）
- [ ] A06 卡片间距 24px、区块间距 32–40px，无拥挤或错位

### Hero 沉浸区
- [ ] A07 封面图 50% 透明度 + 左深右浅渐变遮罩，文字可读
- [ ] A08 TA 照片 128px 圆形，带 `glow.portrait` 辉光（44px + 100px 双层）
- [ ] A09 名字衬线 32px、字距 0.2em；生卒年 13px 弱字、字距 0.35em
- [ ] A10 灯亮状态：小火焰 + 「你点的灯还亮着 · 已持续 3 小时」
- [ ] A11 主 CTA「和 TA 说说话」非全宽（w-56 列内），熔橙渐变 + `glow.cta`；下方分享/编辑/亲友三个次按钮宫格

### 锚点 Tab
- [x] A12 滚动后 Tab 吸顶，背景深色 82% + blur，底部 1px 白 8% 线
- [ ] A13 当前 Tab「记忆」：烛金文字 + 熔橙 2px 下划线；其余为二级文字色

### 内容区
- [ ] A14 时间线左轴单列：年份烛金衬线右对齐 + 熔橙圆点 + 渐隐轴线，4 条事件不错位
- [ ] A15 时间线配图卡（青岛看海）底部渐变遮罩 + 说明文字可读
- [x] A16 供桌：顶部熔橙径向氛围光 + 烛火摇曳动效（≤1.2s 节奏感，无音效）
- [ ] A17 祭品宫格 6 项**一行排开**；免费三项右上苔绿「免费」，付费三项烛金「¥6/¥6/¥19」，价格点击前可见
- [ ] A18 「✨ 为 TA 准备特别的礼物」通栏描边卡片，视觉权重明显低于宫格，无红点/催促元素
- [ ] A19 「留下你的话」：留言/悄悄话/悼文三 chip 单选态清晰（active 烛金描边），字数计数 8/500
- [ ] A20 「最近的纪念」4 条：图标 + 打码昵称 + 相对时间，分割细线白 5%
- [ ] A21 「记忆档案」摘要 3 条 + 「已建立 32 条」（数字烛金衬线）

### 对话侧板
- [ ] A22 初始收起：右缘 56px 竖条，烛金图标 + 竖排「和 TA 说说话」，主内容区**未为其预留任何宽度**
- [ ] A23 首次点击竖条：弹出身份说明层（480px 居中、`#150806` 深色卡、遮罩 55% 黑、无 ×、点遮罩不关）
- [ ] A24 说明层文案逐字：「根据 TA 的文字、故事、照片等资料构建纪念性 AI。它不是 TA 本人，也不能真正代表 TA。」+ 三个能力点 + 唯一按钮
- [ ] A25 确认后：侧板 360px 从右滑入（250ms），覆盖式悬浮（左投影 + blur），主区宽度不变
- [ ] A26 侧板顶栏：TA 头像带烛金辉光 + 「和爷爷说说话」+ 副标题「纪念性 AI · 不是 TA 本人」+ ⋯ + 收起钮
- [ ] A27 气泡：用户右对齐熔橙渐变；TA 左对齐玻璃底；均有推测角标「基于 TA 的资料推测」（11px 弱字）与烛金下划线「查看这句话的依据」
- [ ] A28 回复中态：三点呼吸动画 + 「正在想你问的话…」
- [ ] A29 输入栏玻璃胶囊 + 🎙 置灰 40% + 熔橙发送钮；快捷 chip 2 条在输入框上方
- [ ] A30 再次刷新页面：说明层不再出现（localStorage 记忆），侧板展开/收起状态保持
