## 二、视觉规范（延续移动端熔火/余烬主题，仅列 PC 差异）

### 2.1 色彩与质感系统（以 `prototype/shared/ui.css` 为准，全端统一）

> **色板与全部视觉令牌以 [`设计令牌.md`](./设计令牌.md) 为单一事实来源（SSOT）**；本节仅为概览，色值/渐变/辉光/动效参数若不一致，以设计令牌文档为准。

| 角色 | 色值 | 用途与限制 |
|---|---|---|
| 背景 · 深黑 | `#070302`（`--bg`） | 全局底色，叠加熔橙径向氛围渐变（顶部/底部各一处，克制） |
| 主色 · 熔橙 | `#FF7A2F`（`--ember`） | 主 CTA、点灯/供奉动作、当前态标识 |
| 点缀 · 烛金 | `#FFB35C`（`--ember-soft`） | 强调文字、年份、链接、图标点缀 |
| 深橙 | `#B43A0E`（`--ember-deep`） | 渐变收尾、品牌块 |
| 成功 · 苔绿 | `#7FB069`（`--ok`） | 「免费」标、供奉完成 |
| 警示 · 余烬红 | `#E0604F`（`--danger`） | 删除等破坏性操作 |
| 文字 | 主 `#FFF6EC` / 次 `rgba(255,246,236,.6)` / 弱 `rgba(255,246,236,.38)` | 三级文字透明度 |
| 卡片 | `rgba(255,255,255,.05)` + 1px `rgba(255,255,255,.09)` 细边 | 玻璃卡片，配 backdrop blur |

- 质感：**发光球体、烛火、玻璃卡片、橙色辉光是本产品的既定视觉资产**，全端保留；辉光仅用于 Hero 照片、品牌块、供桌顶部氛围三处，不得扩散到普通内容卡片。
- 字体：标题衬线（Noto Serif SC / 宋体系），正文无衬线（PingFang / 雅黑系），与移动端一致。
- 圆角：卡片 12–22px（内容卡 12，Hero/弹层 22+），主按钮全圆角。

### 2.2 PC 差异项

| 项 | 移动端 | PC 端 |
|---|---|---|
| 字号阶梯 | 24 / 17 / 16 / 13 | 32(Hero 名) / 20(区块标题) / 14–15(正文) / 11–12(辅助)；行高仍 1.6 |
| 可点区域 | ≥44×44pt | ≥36×36px；主 CTA 高 48–52px，**不全宽**，宽度 ≤320px |
| 悬停态 | 无 | 所有可点元素必须有 hover 态（背景白 4% 或透明度 85%），过渡 150ms ease-out |
| 焦点态 | — | 键盘 Tab 焦点环：2px 烛金（`--ember-soft`）外描边，offset 2px（无障碍强制） |
| 动效 | 200–300ms | 同；侧板展开/收起 250ms ease-out；禁止弹跳 |
| 滚动条 | 隐藏 | 细滚动条 6px，thumb `rgba(255,255,255,.12)` 圆头 |

## 三、布局框架

### 3.1 总体结构

```
┌────────────────────────────────────────────────────────────┐
│ 左导航 224px（固定）│  主内容区（滚动，max 1120px 居中）  │ 对话侧板 │
│  · 品牌区            │                                    │ 收起:56px│
│  · 纪念馆            │   ┌─ Hero 沉浸区 ─────────────┐   │ 展开:360px│
│  · 发现（后续）       │   │ 照片 名字 生卒 寄语 CTA    │   │（覆盖式， │
│  · 我的              │   └──────────────────────────┘   │ 不挤压主区）│
│  · 底部用户卡         │   记忆 │ 想念 │ 祭奠（吸顶锚点）  │          │
│                    │   ┌ 8 列 ────────┐ ┌ 4 列 ──────┐ │          │
│                    │   │ TA 的人生      │ │ 留下你的话    │ │          │
│                    │   │ 祭奠供桌/宫格  │ │ 最近的纪念    │ │          │
│                    │   │              │ │ 记忆档案摘要  │ │          │
│                    │   └──────────────┘ └────────────┘ │          │
└────────────────────────────────────────────────────────────┘
```

- **左导航 224px**，`position: fixed`，深色半透明 + backdrop blur；内容项与移动端一级导航一致：纪念馆 / 发现（后续阶段，置灰）/ 我的；馆内区块（记忆/想念/祭奠/亲友）**不**进左导航。
- **主内容区**：`margin-left: 224px`，内部容器 `max-width: 1120px; margin: 0 auto; padding: 32px 40px`。
- **对话侧板**：`position: fixed; right: 0; top: 0; height: 100vh`。收起态为右缘 56px 竖条（烛金图标 + 「和 TA 说说话」竖排）；展开态 360px，深色毛玻璃**覆盖式**（悬浮于内容之上），不挤压主区宽度。首次使用仍必经身份说明弹层（§4.3，文案逐字同移动端 §2.3，不可删改）。

### 3.2 断点系统

| 断点 | 宽度 | 行为 |
|---|---|---|
| ≥1440px | 宽屏 | 12 列网格：内容 8 列 + 右辅助栏 4 列 |
| 1024–1439px | 常规桌面 | 主区退化为单列：TA 的人生 → 祭奠 → 留下你的话 → 最近的纪念 → 记忆档案摘要，顺序同移动端信息流 |
| 768–1023px | 小窗/平板横屏 | 左导航收起为 64px 图标栏；主区单列 |
| <768px | — | 提示「请使用手机访问」或跳转移动站，不做降级适配（V1 范围外） |

### 3.3 网格与间距

- 12 列网格，列间距 24px；卡片间距 24px；区块间距 32–40px。
- 卡片内边距 24px；Hero 区内边距 32px。
- 信息密度主动留白原则同移动端：一屏不追求塞满。

## 四、页面设计图纸（PC 适配版）

> 仅描述与移动端的**差异**；控件清单、文案、三态（空/加载/错误）定义逐条继承 `前端具体设计流程.md` §二，PC 端不得另造文案。

### 4.1 纪念馆首页 ★★★★★

- Hero 沉浸区：背景封面图 50% 透明度 + 左深右浅渐变遮罩；横向布局——左为 TA 照片（128px 圆形，**保留移动端的发光辉光** `0 0 44px rgba(255,122,47,.55)`），中为名字（衬线 32px）/ 生卒年 / 寄语 / 灯亮状态（小火焰 + 「灯还亮着」自然文案），右为操作列（主 CTA「和 TA 说说话」+ 分享/编辑/亲友三个次按钮宫格）。
- Tab 锚点条：吸顶（`top: 0`），深色 82% 透明度 + backdrop blur + 底部 1px 白 8% 分割线；当前 Tab 熔橙 2px 下划线 + 烛金文字。
- 「TA 的人生」时间线：左轴单列（年份烛金衬线 + 熔橙圆点 + 渐隐轴线），同移动端；事件 ≥6 条时可选左右交错，稀疏内容不强行交错。
- 祭奠区：供桌横幅（顶部熔橙径向氛围光 + 烛火动效保留）+ 6 项宫格一行排开（不再 3 列换行）；免费标苔绿、付费标 ¥X 烛金，价格点击前可见；「✨ 为 TA 准备特别的礼物」为通栏描边卡片，权重低于宫格。
- 右辅助栏（4 列）：依次「留下你的话」「最近的纪念」「记忆档案摘要」。「留下你的话」提交成功 toast 与列表刷新规则同移动端。

### 4.2 想念表达

PC 不单设想念页：「留下你的话」卡片常驻首页右辅助栏；「你留下的」历史列表以弹层或二级路由 `/miss` 呈现，布局为居中 640px 单列。

### 4.3 身份说明弹层（首次必经）

PC 为**居中弹层**（宽 480px，深色卡片 `#150806` + 细边，遮罩 55% 黑 + 轻 blur，**不可点遮罩关闭、无右上角 ×**，唯一出口是底部按钮），声明文案逐字同移动端 §2.3。确认后写入本地态并展开对话侧板。

### 4.4 对话侧板 ★★★★★

- 容器：360px 覆盖式，深色 92% 底 + backdrop blur + 左侧 1px 白 8% 边 + 左投影；250ms ease-out 滑入滑出。
- 顶栏：TA 小头像（带烛金辉光）+ 「和 + 称谓 + 说说话」+ ⋯（清空对话/反馈问题）+ 收起按钮；副标题「纪念性 AI · 不是 TA 本人」。
- 消息区：**沿用移动端气泡样式**——用户气泡右对齐熔橙渐变底白字；TA 气泡左对齐玻璃卡底 + 细边；气泡最大宽度为侧板宽 78%；「查看这句话的依据」11px 烛金下划线文字链（无依据不显示）；推测角标 11px 弱字；日期分隔线「── 今天 ──」弱字细线。
- 「回答依据」为侧板内弹层（不新开全局弹窗）。
- 补充记忆闭环：AI 不知道时气泡下方「添加一段关于 TA 的记忆」→ 侧板内表单 → 保存 toast「已保存到 TA 的记忆档案」→ 回到对话。
- 快捷 chip：空对话时横排在输入框上方，对话开始后隐藏。
- 输入框：底部固定玻璃胶囊（`inputbar`），占位「想对 TA 说……」，🎙 置灰占位（点击 toast「语音功能正在准备中」），Enter 发送 / Shift+Enter 换行。
- 状态：回复中三点呼吸动画 + 「正在想你问的话…」可中断；错误「刚才没说上话，再试一次」+【重试】；敏感内容「这个话题我们轻轻带过」。
- 埋点同移动端 §五。

### 4.5 记忆档案

- 二级路由 `/archive`，主区单列（max 760px 居中）：顶部「已建立 N 条记忆」+ 五分区卡片（👤/❤️/🎵/💬/📄），分区空状态文案逐字同移动端。
- 底部固定【＋ 添加记忆】改为页面右上主按钮；添加流程为居中弹层（选分区 → 录入 ≤500 字 → 保存 toast）。
- 编辑/删除：hover 条目右侧浮现操作图标；删除必经二次确认弹窗（余烬红标识）。
- 首页右栏「记忆档案摘要」展示 3 条 + 条数，点击进 `/archive`。

### 4.6 祭奠与 AI 生成纪念物

- 一口价确认弹窗：宽 400px 居中深色卡片，元素白名单（图标+名称+价格+说明+双按钮）逐字同移动端 §六-3，禁止倒计时/库存/攀比；遮罩 55% 黑，点遮罩=取消。
- 供奉成功：供桌即时刷新 + ≤1.2s 烛火温和动效，无音效（默认关闭）；点灯后 Hero 区「灯还亮着」自然文案。
- AI 生成纪念物为二级路由 `/gift` 三步流：PC 上三步为**横向步骤条 + 单卡片**（顶部 1→2→3 步骤指示，内容区单卡切换），第 3 步纪念物大图居中展示，按钮组【收藏到纪念馆】【分享给亲友】【再准备一件】。
- 「帮我写」每日限量提示、失败自动退费提示，文案同移动端。

### 4.7 我的

二级路由 `/me`：主区单列 max 760px——用户卡（头像/打码昵称/守护天数）、个人资料、我的纪念（创建/协作/纪念过三态聚合）、订单记录（一口价流水表格：时间/项目/金额/状态，支持分页）、设置（通知/隐私/注销）。

### 4.8 亲友共同纪念

二级路由 `/family`：馆主可生成/更换邀请链接（复制按钮 + 二维码可选）；成员列表打码展示；访客态与权限规则完全由服务端视图模型 `viewerRole` 驱动，前端不自行推断。

## 九、首页概念稿落地（2026-08-23）

概念稿 `docs/web/concept/index.html`（截图 `shot-1-candle.png` / `shot-2-dusk.png` / `shot-3-star.png`）已落地为**项目首页** `/[lang]`。

### 9.1 实现

- 组件：`src/app/[lang]/ConceptHome.tsx`（客户端组件），路由页 `src/app/[lang]/page.tsx` 仅做 lang 解析后渲染。
- 视觉：WebGL 折叠光绸着色器（fbm 域扭曲 + 正弦折叠），四组色板「烛夜 / 黄昏 / 晨雾 / 星夜」由右下角「换个意境」按钮逐帧插值切换；鼠标视差缓动跟随。
- 降级：无 WebGL 时移除 canvas，露出 CSS 静态径向渐变；`prefers-reduced-motion` 时光流速度降至 0.15。
- 性能：`devicePixelRatio` 上限 2；单全屏三角形 + rAF 循环，无外部依赖。
- 版式：在站点布局（NavBar 高 4rem）内全屏呈现，容器高 `calc(100vh - 4rem)`；主标题「彼岸」（宋体系字族）+ 标语「思念有处安放」+ CTA「进入彼岸」→ `/[lang]/garden`。英文语言下标题/标语/CTA 显示对应英文。
