# 彼岸 · 单屏互动原型改造方案

> 背景：`prototype/index.html` 原为 10 个独立 HTML 的 iframe 平铺总览（走查用），各屏之间不能互相跳转。
> 目标：**合成 1 屏**——一部 Redmi K90 至尊版手机框（400×866）内承载全部页面，点击按真实信息架构导航，带移动端转场与手势反馈，数据来源不变（`shared/api.js` → 真实后端 `/api/*`）。
> 访问入口不变：`/proto/index.html`。本文是改造的唯一实施依据。

---

## 一、形态定义

```
┌─────────────────────────────┐
│   彼岸 · 线上祭奠 App        │ ← 壳外仅保留一句说明（不再是平铺画廊）
│  ┌───────────────────────┐  │
│  │  ┌─────────────────┐  │  │
│  │  │   当前视图       │  │  │ ← 单手机框 · 居中打孔 · 400×866
│  │  │  （一屏一视图）   │  │  │
│  │  │                 │  │  │
│  │  │  底部导航×3      │  │  │ ← 纪念馆 / 发现 / 我的
│  │  └─────────────────┘  │  │
│  └───────────────────────┘  │
│  ?id= 透传 · 视图栈说明      │
└─────────────────────────────┘
```

- **单手机框**：只保留一个 `.phone` 外壳；不再有 iframe 矩阵。
- **视图（View）**：原 10 屏各变成一个视图片段（HTML partial），同一时刻只渲染一个。
- **导航**：视图内点击（主 CTA、宫格、列表项、底部 Tab）触发视图切换，不再整页跳转。
- **弹层态**：身份说明、一口价确认、添加记忆抽屉、依据弹层，作为**视图内浮层**（overlay），不再是独立页面。

## 三、技术方案

1. **目录结构**（prototype/ 下重组，旧文件保留作走查备份）：
   ```
   prototype/
     index.html            # 单屏壳：手机框 + 视图容器 + 浮层容器 + Toast
     shared/ui.css         # 不变（视觉语言）
     shared/api.js         # 不变（BianApi，已接真实后端）
     shared/router.js      # 新增：微型视图路由（视图栈/转场/浮层管理，无依赖）
     views/home.html …     # 原 10 屏 <body> 内的 .screen 内容抽为 partial
     legacy/               # 原独立整页移入存档（可选）
   ```
2. **路由（shared/router.js）**：
   - `go(view, params)` 推入视图栈；`back()` 出栈；`overlay(name, data)` / `closeOverlay()` 管理 F1–F4；
   - 视图切换动效：右进左出 200–300ms ease-out（对齐设计规范 §1.4）；浮层自底部升起，遮罩 40% 黑，点遮罩=取消；
   - 视图用 `fetch('views/x.html')` 取片段注入容器，注入后执行该视图的 init（每视图一个 `init(root, ctx)`，放在 `views/x.js` 或内联 `<script data-view>`，由 router 调用）；
   - `?id=` 存在 ctx 全局，所有视图共享；V7 点选其他馆时更新 ctx.id 并刷新 V1。
3. **数据层零改动**：各视图 init 里调用现有 `BianApi.*`（上一轮已接好：纪念馆/时间线/feed/供奉/留言/记忆 CRUD/对话+历史+清空/我的+订单）。原整页脚本逻辑平移进各视图 init。
4. **状态保持**：对话页视图离开不销毁（keep-alive：V3 DOM 缓存），返回时保留滚动位置；其余视图每次进入重新拉数据。
5. **CSP 兼容**：`/proto/*` 已放行 `'unsafe-inline'` 与 Tailwind CDN，视图片段内联脚本由 router `eval` 或改为外置 `views/*.js`（**首选外置**，规避 CSP 与 eval 风险）。

## 四、文案与红线（继承，不新增例外）

- F1 声明文案逐字使用，不可删改；F2 弹窗元素白名单=图标+名称+价格+说明+双按钮。
- 底部 Tab「发现」置灰，点击 toast「『发现』为后续阶段」。
- 无充值/礼包/打榜；付费只有一口价提示。

## 五、实施步骤（改造时按此执行）

1. 建 `shared/router.js`（约 120 行：栈、转场、浮层、片段加载、init 调用）。
2. 抽 8 个视图 partial + 4 个浮层 partial（从现有整页复制 `.screen` 内结构，去掉 statusbar/外层壳）。
3. 重写 `index.html` 为单壳：手机框 + `<main id="view">` + `<div id="overlay">` + 底部「查看 PC 端」链接。
4. 平移各页已接好的 API 脚本到对应视图 init（home/miss/chat/memory/offering/profile 六个视图有真实逻辑；gift 演示态；offering-pay/chat-intro/memory-add 转浮层）。
5. 导航接线按 §二导航边逐条过；返回栈与 keep-alive 验收。
6. 冒烟：`tools/check-proto-serve.mjs` 扩展断言——`/proto/index.html` 含视图容器、`shared/router.js` 200、`views/*.html|js` 全部 200；视图逻辑冒烟沿用既有 API 冒烟（数据层未动）。
7. 旧平铺版如需保留走查：整体移到 `prototype/legacy/`，`/proto/legacy/index.html` 可访问。

## 六、验收口径

1. 一部手机框内可完成全链路：看 TA（V1）→ 说说话（F1→V3，有依据/推测/补充记忆闭环）→ 补记忆（F3→回 V3 toast）→ 留言（V2 三类型）→ 献花点灯（V5，供桌/feed 刷新）→ 付费弹窗（F2 白名单元素）→ 我的（V7 登录态/聚合/订单）。
2. 转场 200–300ms 无弹跳；浮层遮罩点击可关；返回栈不丢层级。
3. 键盘弹出输入框吸附（V3/V2 输入场景）安全区不遮挡。
4. 所有数据真实来自 `/api/*`；未登录态各写操作提示登录（现状语义不变）。
5. `?id=` 切换纪念馆后全视图生效。
