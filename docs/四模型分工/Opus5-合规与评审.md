## 二、任务 B：每周漏斗周报（每周五）

### B1 周报执行流程（每周五）

**触发条件**：周五（或约定时间）向刘贻清获取数据快照

**执行步骤**：
1. [ ] 步骤1：请求刘贻清提供 `GET https://bianmuyuan.cn/api/admin` 返回的 `funnel` 对象 JSON
2. [ ] 步骤2：请求近30天事件统计数据（events表聚合）
3. [ ] 步骤3：按模板填入数据，计算各环节转化率
4. [ ] 步骤4：识别低于目标门槛的环节
5. [ ] 步骤5：结合数据趋势给出诊断与下周唯一重点
6. [ ] 步骤6：保存到 `docs/周报/YYYY-MM-DD-第N周.md`

**目标门槛**（来自PRD 3.0）：
| 指标 | 目标门槛 |
|---|---|
| 建馆→7日共享率 | ≥70% |
| 共享→入群率 | ≥50% |
| 入群→祭奠完成率 | ≥60% |
| 全链完成率 | ≥21% |
| 周活跃祭奠馆 | ≥50 |
| 馆主30日回访率 | ≥25% |

### C4 常见问题快速检查清单

#### 支付安全
```
# 验签必须存在
rg "verify|validate.*signature|check.*sign" src/app/api/stripe src/app/api/payment

# 金额单位为分
rg "amount|fee|price" src/lib/payment src/lib/stripe
# 确认乘以100或使用整数分

# 幂等表约束
rg "payment_events" migrations/
```

#### 权限安全
```
# 新API必须有auth检查
rg "requireAuth|getSession|permissions\." src/app/api/

# owner校验
rg "owner|creator|uid.*===|userId.*===" src/app/api/memorials src/app/api/items
```

#### 数据安全
```
# 无密钥硬编码
rg -i "sk-|AKIA|private.*key" src/ --type-add 'config:*.{ts,js}' --type config

# SQL参数化
rg "\`.*\$\{" src/ --type-add 'sql:*.{ts,sql}' --type sql
```
