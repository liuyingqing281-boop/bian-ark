# 墓园页面前端设计规格

## 1. 目标与视觉基调

- 目标：沉浸式悼念体验与高效浏览并重。
- 场景使用深色石色系与暗铜烛光金；四季主题只覆盖雾气、植被、星光等环境 token。
- 材质偏写实，数字化处理克制；场景无框铺满，浮层柔和过渡。
- 视觉层级：场景 > 墓位信息 > 操作。

## 2. 页面骨架

- 场景全宽全高，背景与氛围层 `z-0`，墓位交互层 `z-10`。
- 顶部悬浮导航与场景控制 `z-20`：返回、搜索、2.5D/3D 分段控件；低频设置进入更多菜单。
- 底部抽屉、详情与供奉面板 `z-30`；临时提示最高 `z-40`。
- 导航和抽屉背景全宽，内部内容限宽居中。
- 所有浮层使用 `position: fixed`；场景不参与文档流。

## 3. 抽屉与浏览

- 统一使用底部抽屉：收起、半展开、全展开三态。
- 移动端收起约 `64–72px`，半展开为可视高度 `45%–55%`，全展开保留顶部安全区。
- 支持把手、按钮、拖拽和键盘操作；移动端仅顶部安全区调整高度，正文独立滚动。
- 桌面端使用固定宽度横向卡片轨道，按空间显示约 2–6 张；连续滚动，不分页。
- 卡片摘要：头像/占位符、姓名、生卒年份、最多两行墓志铭。详情中完整展开。
- 搜索固定在顶部；输入姓名、别名、墓志铭，防抖 `300–500ms` 后更新抽屉结果。
- 筛选入口位于抽屉首行；简单条件即时更新，复杂条件点击应用；支持单项移除和全部清除。
- 搜索无结果保留场景与当前选中墓位；筛选不匹配墓位降亮但不隐藏。

## 4. 详情与供奉

- 点击墓位后执行 `400–700ms` 可中断平滑聚焦，并切换抽屉为详情模式。
- 详情结构：固定身份摘要、独立滚动正文、固定底部双主操作。
- “供奉”和“查看完整纪念页”为并列主操作；窄屏或大字号时纵向堆叠，供奉在上。
- 供奉在抽屉内完成；祭品横向选择且首期单选，祭品必选、留言可选。
- 提交中防重复点击；失败保留输入并原地重试。成功显示 `800–1200ms` 反馈后返回详情，场景仅做不超过 `1.2s` 的轻量烛光反馈。
- 未提交内容离开时才确认；媒体不自动播放，切换墓位或离开页面时停止并释放资源。

## 5. 2.5D / 3D

- 切换视图保留墓位、搜索、筛选、抽屉和镜头状态；3D 失败自动回退 2.5D。
- 3D 只负责渲染与镜头，墓位热区、标签和键盘焦点使用独立 2D 交互层。
- 2D 层与 3D 共享空间数据，运动期间用 `requestAnimationFrame` 投影，静止后停止高频更新。
- 热区至少 `44 × 44px`；重叠按选中、匹配/聚焦、深度排序，无法判断时显示候选菜单。
- 桌面支持缩放、拖拽、复位；移动端复位按钮与双指缩放。复位只改变镜头，不清除浏览状态。

## 6. 动效、性能与无障碍

- 动效档位：完整、简化、静态；低性能设备只降低默认值，用户可恢复。
- 时序：微交互 `120–180ms`；抽屉/列表 `240–360ms`；聚焦/页面过渡 `400–700ms`；仪式反馈 ≤ `1.2s`。
- 同一时刻只保留一个主过渡；`prefers-reduced-motion` 下静态或 `0–100ms`。
- 场景底图先可交互，雾气、萤火、材质渐进加载；列表使用固定尺寸骨架和可见区域虚拟化。
- 键盘以抽屉列表为主；抽屉打开时焦点进入并限制在内部，`Escape` 返回上一级，关闭后恢复触发控件。
- 正文对比度 ≥ `4.5:1`；焦点环统一使用清晰 `2px` amber；状态不能只靠颜色表达。
- 动效、音效、对比度和字号偏好写入 `localStorage`；墓园浏览状态使用 URL / `sessionStorage`。

## 7. 状态与验收

- URL 仅同步视图、搜索、筛选、墓位 ID 和抽屉模式，不写入像素高度或镜头坐标。
- 浏览器后退按层级回退：供奉 → 详情 → 列表 → 搜索/筛选历史 → 离开页面。
- 视觉 token 统一放在 `globals.css` CSS 变量；组件引用语义变量，不散落硬编码。
- 验收分三层：Playwright 与键盘/触控功能、固定视口视觉基线、真实移动端滚动/拖拽/帧率/溢出/reduced-motion。
