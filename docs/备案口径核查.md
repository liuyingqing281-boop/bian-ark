# 备案口径核查

> 检索日期：2026-08-19

## 口径结论

### 1. 重庆主体口径

**结论**：
- 算法备案是**国家统一制度**，地方网信部门仅负责材料接收，无地方性特殊要求
- **有限责任公司**可正常申请，需提供：
  1. 营业执照（统一社会信用代码）
  2. 法定代表人身份证
  3. 算法安全责任人身份证明（可与法人相同）
  4. 《备案承诺书》（系统提供模板）
  5. 《工作证明》（系统提供模板）
  6. 《落实算法安全主体责任基本情况》（描述企业算法安全组织与制度）
  7. 《算法安全自评估报告》
  8. 《拟公示内容》

**重庆无单独材料要求**，执行国家统一标准

**待确认**：
- [ ] 刘贻清：企业主体是否已注册完成（营业执照是否在手）

### 2. 域名/服务器口径

**问题**：.cn 域名 + 香港服务器（无ICP备案）在填报「产品及功能信息」时的网址填写口径

**结论**：
- 填报「产品及功能信息」时，**产品访问地址**字段填写实际可访问网址 `https://bianmuyuan.cn`
- 香港服务器 + .cn 域名属于有域名但服务器在境外的混合情况
- 建议：
  1. 直接填写 `https://bianmuyuan.cn`
  2. 如系统要求补充ICP备案号，可在备注说明「服务器位于香港数据中心」
  3. **建议电话确认**（010-82990520/82990521），香港服务器口径是常见问题，官方有标准答复

**待确认**：
- [ ] 刘贻清：拨打电话 010-82990520 确认香港服务器口径
