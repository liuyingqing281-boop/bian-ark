# 祭品资产规范

- 画布：512 x 512 px，透明底 WebP；生成源允许白色无缝背景，落盘时使用透明画布 `contain`。
- 构图：单一主体居中，主体占画布约 72%，正面略俯视 15 度。
- 光线：左上方柔和主光，右下方轻微接触阴影；禁止强烈投影、彩色背景和高光溢出。
- 风格：克制的写实产品摄影，不出现人物、文字、水印、品牌标识和装饰边框。
- 命名：与数据库 item id 一致，格式为 `<item-id>.webp`。
- 交付：资源位于 `data/uploads/items/official/`，`manifest.json` 记录尺寸、格式、体积和 SHA-256。
- 页面：始终使用固定正方形容器；图片失败或旧数据无图片时使用数据库 emoji 作为 fallback。
