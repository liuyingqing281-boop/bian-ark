## 一、系统与访问链路

```
浏览器 ── https://bianmuyuan.cn (443, Let's Encrypt, certbot 自动续期)
       └─ Nginx（/etc/nginx/sites-available/bian，软链 sites-enabled）
          └─ proxy_pass → 127.0.0.1:3002
             └─ PM2 进程「bian」：npm run start -- -p 3002（root 运行，fork 模式，max_memory 400M）
                └─ Next.js 16 App Router 单进程
                   ├─ SQLite（/var/www/bian/data/bian.db，WAL 模式，better-sqlite3 单例）
                   └─ 本地磁盘上传（/var/www/bian/data/uploads/，经 /uploads/[...path] 读回）
```
