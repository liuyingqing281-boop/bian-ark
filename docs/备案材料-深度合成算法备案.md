## 四、《算法安全自评估报告》草稿（核心文件）

> 按官方模板七大章节撰写；下述内容均已与代码实现一一对应，可放心填写

### 4.1 算法基本信息

- **算法名称**：彼岸多模态生成合成算法（含图像生成、视频与语音合成、文本生成、对话语音合成与音色复刻四个子能力）
- **算法类型**：生成合成类（深度合成）——图像、视频、音频、文本
- **应用领域**：互联网信息服务——网络祭奠/纪念馆服务
- **服务形式**：网站（含移动端自适应网页）
- **算法角色**：深度合成服务提供者
- **基础模型来源**：非自研。调用火山引擎（北京火山引擎科技有限公司）「火山方舟」平台的第三方基础模型 API（doubao-seedream 图像生成、doubao-seedance 视频生成、doubao 对话模型），以及小米（北京小米移动软件有限公司）「MiMo 开放平台」的第三方语音模型 API（mimo-v2.5-tts 语音合成、-voicedesign 音色设计、-voiceclone 音色复刻），本产品不进行模型训练与微调，仅做应用层服务编排与内容安全管控

### 4.2 技术架构与实现原理

1. **图像生成**：用户输入祭品描述文本（≤100 字），经内容安全审核后调用火山方舟图像生成 API 生成写实风格祭品图片，生成结果经压缩转存后展示于纪念馆页面。每用户每月免费配额 3 次，超出需付费会员
2. **视频与语音合成**：用户（限逝者近亲属，需勾选肖像与声音授权声明）上传逝者正面照片并输入文稿（≤500 字），系统调用视频生成 API 合成数字人说话视频（自动加「AI 生成」水印），生成结果进入人工审核队列，审核通过后方可公开展示
3. **文本生成**：用户输入简短描述，调用对话模型扩写为提示词文本，全程内容安全审核（开发中，填报时注明「建设中」）
4. **对话语音合成与音色复刻**（2026-08-23 增补）：对话场景中用户点击朗读，系统将对话文本（≤500 字，先经内容安全审核）调用 MiMo 语音合成 API 生成语音流播放（不自动播放、不落库音频）。音色复刻仅限逝者近亲属：强制勾选「我是逝者近亲属或已获合法授权」声明（consent 记录入库）并上传生前语音样本，复刻申请进入人工审核队列，审核通过后音色方可使用；以复刻音色播放的内容页面标注「AI 合成声音」。语音识别（语音转文字输入）不产生合成内容，属语音理解能力，一并说明

技术要点：所有生成请求均经服务端统一入口；素材（照片/声音）本地加密存储，仅传输至模型 API 用于本次生成；不将用户数据用于任何模型训练

### 4.3 数据安全评估

- **数据收集**：仅收集服务必需信息（账号、上传素材、生成记录）；数字人功能强制近亲属授权确认（consent 记录入库）
- **数据存储**：部署于境内服务器，数据库与文件存储于本地磁盘；传输全程 HTTPS 加密
- **第三方传输**：生成请求经 HTTPS 传输至火山方舟 API（境内）与小米 MiMo 开放平台 API（语音合成/音色复刻），仅传输本次生成所需素材；依据用户协议，任务完成后素材按期限删除（复刻声音样本保存期限 90 天，到期离线清理）
- **数据删除**：用户可申请导出与删除个人数据（产品已实现 data_requests 流程）；纪念馆删除时级联清理全部素材与生成物

### 4.4 内容风控机制（全部已实现）

1. **生成前审核**：所有用户输入文本（提示词、文稿、留言、祭品名称）经内容安全审核（阿里云内容安全 API + 人工兜底）过滤违法违规内容
2. **生成后审核**：AI 生成祭品、数字人视频均进入人工审核队列，管理员审核通过后方可对公众展示
3. **AI 生成标识**：数字人视频强制添加「AI 生成」水印与页面角标；图像生成物在展示场景标注 AI 生成来源
4. **违法内容处置**：管理员可下架违规内容；用户可通过申诉通道（moderation_appeals）发起申诉
5. **日志留存**：全量操作事件（生成、审核、登录）与内容审计日志留存，满足不少于 6 个月的监管要求

### 4.5 伦理与用户权益保护

- **肖像与声音保护**：数字人生成强制勾选「我是逝者近亲属或已获合法授权」声明并留存授权记录；禁止名人生成（人工审核把关）
- **未成年人保护**：会员付费与 AI 生成均要求登录账号；祭奠场景不向未成年人推送
- **防沉迷与滥用**：免费配额限制（3 次/月）+ 付费会员制，防批量滥用
- **知情权**：用户协议与隐私政策含 AI 生成内容条款、逝者数据处理条款、声音克隆限制条款、素材限期删除条款（均已上线 /legal/terms、/legal/privacy）

### 4.6 算法安全事件应急处置

- 生成服务异常（API 故障/超时）：自动失败并退还用户已支付额度，服务降级为关闭生成入口
- 发现违法有害生成内容：管理员一键下架 + 溯源日志 + 依法向主管部门报告
- 模型输出安全事件（如越权生成）：内容审核前置拦截 + 审核队列拦截双保险
- 应急联络：算法安全责任人 24 小时可达

### 4.7 自评结论与合规承诺

本算法基于境内第三方基础模型提供生成合成服务，已建立覆盖生成前审核、生成后审核、显著标识、授权确认、日志留存、用户申诉的全流程安全机制，符合《互联网信息服务深度合成管理规定》《互联网信息服务算法推荐管理规定》要求。承诺备案信息真实有效，算法变更时及时履行变更备案手续。

## 五、《拟公示内容》草稿（备案通过后对外公示的简介）

> 算法名称：彼岸多模态生成合成算法
> 算法基本原理：基于第三方基础模型（火山方舟 doubao 系列、小米 MiMo 语音模型系列），根据用户输入的文本描述及授权上传的人物照片、声音样本，生成祭奠场景使用的图像、数字人视频、提示词文本及角色语音。产品不对基础模型进行训练或微调。
> 算法目的意图：为网络祭奠用户提供个性化祭品图像与逝者数字人纪念内容，提升线上缅怀的情感表达。
> 服务形式：网站（含移动端网页）。

## 六、算法安全管理制度框架（如需单独上传的 PDF 大纲）
