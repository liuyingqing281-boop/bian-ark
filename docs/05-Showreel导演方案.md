# 彼岸 · 产品 Showreel 导演方案（30s @ 30fps = 900 帧）

- 依据角色规范：Product Showreel Director & Motion Engineer
- 产物：`/[lang]/showreel` 路由（帧驱动、可拖帧审计）
- 素材原则：使用项目真实 UI 语言（墓园石碑 / 建馆向导 / 馆主页 / 记忆档案 / 缅怀对话 / 祭堂祭品 / 留言墙），人名全脱敏（「李**」），逝者「王秀兰」为虚构示例

---

## 0. 产品理解（先理解产品，再修改动画）

| 问题 | 答案 |
|---|---|
| 这是什么产品 | 彼岸纪念馆：为逝去的亲人、宠物、想念的人建一座线上纪念馆，可记录故事、留言、献花点灯、与"基于记忆档案"的缅怀对话 |
| 谁会使用 | 异地/海外中青年悼亲者（主）、中老年高频悼念者、家族组织者 |
| 用户最核心的问题 | 无法到场祭扫，思念无处安放；现有产品诱导付费、阴森、不真实 |
| 最重要的 3–6 个功能 | ① 3 步建馆向导 ② 记忆档案（生平/相册/时间轴）③ 缅怀对话（带「基于 TA 的资料推测」诚实角标+记忆引用）④ 献花点灯祭堂 ⑤ 留言墙/悄悄话 ⑥ 公共墓园 |
| 完整价值路径 | 进入 → 建馆 → 记录记忆 → 想念时说话/对话 → 献花点灯 → 亲友共祭 → 思念有处安放 |
| 30s 最值得展示 | 建馆向导、馆生成、记忆→对话闭环、点灯联动 |
| 辅助不占主镜头 | 年卡/会员、后台审核、族谱导出、适老模式 |
| 最值得被记住的结果 | 一座有照片、有故事、能说话、能点灯的馆——"思念有处安放" |

## 1. 产品内容链

```
进入公共墓园（思念的现场）
↓ 点击「＋ 为 TA 建一座馆」
3 步建馆向导：TA 是谁 → TA 的故事 → 确认生成
↓ 系统生成纪念馆
馆主页：头像 / 生平 / 时间轴逐一建立
↓ 写入一段记忆（记忆档案 +1）
缅怀对话：提问 → AI 基于记忆回答 → 记忆引用卡 + 追问
↓ 进入祭堂
选择蜡烛 → 点亮 → 烛火燃起 → 祭奠记录错峰上墙（李**/王**/张**）
↓ 拉远
万家灯火的墓园全景 → 「思念有处安放 · 彼岸」
```

## 2. 帧级导演方案 Frame Plan（含 Frame Overlap）

### S0 F000–F104｜墓园夜景 → 建馆入口
- F000–F026：夜景建立——星空渐显，6 块石碑错峰升起（间隔 3–4 帧），萤火虫出现；相机 scale 1.06→1.00 缓慢前推
- F020–F044：「彼岸 · 公共墓园」标题淡入上移；「今夜新增 3 座馆」计数浮现
- F036–F058：光标自右下进入 → 移向「＋ 为 TA 建一座馆」按钮；F050 按钮 hover 高亮
- F058–F064：按钮按下（2 帧方向预示 + 4 帧主位移）
- F062–F104：**大运动①** 相机推入按钮，按钮连续放大变形为向导面板（Position/Scale/Shape 保持）；墓园后退、暗化

### S1 F096–F340｜建馆向导 3 步 → 生成纪念馆（第一次视觉高潮）
- F096–F120：向导面板落定中央（约占宽 52%）；步骤条 1/3 高亮
- F118–F150：输入框聚焦打字「王秀兰」；关系 chips 出现，F146 选中「外婆」
- F150–F176：生卒年滚入 1948 / 2023
- F172–F180：点击「下一步」
- F176–F196：步骤 1 左移退出 / 步骤 2 右移进入（错峰 4 帧）；步骤条 2/3 提前高亮
- F196–F240：生平简介逐字「她总是先问我们，吃饭了没。」；「记忆档案已附带 · 5 个分区」标签错峰浮现
- F238–F248：点击「下一步」
- F246–F266：确认卡进入：头像 / 名字 / 生卒 / 墓志铭 错峰浮现（3 帧间隔）
- F262–F300：点击「生成纪念馆」→ 按钮内花瓣生成动效（非通用圆环）
- F296–F340：**大运动②** 确认卡头像+姓名向前放大，面板其余后退散开；头像光晕扩大，连续落入馆主页（overlap 至 F356）

### S2 F330–F640｜馆主页建立 → 写入记忆 → 缅怀对话（连续操作与系统联动）
- F330–F380：馆主页建立——封面暖光落下、头像自确认卡位置连续落位、名字+生卒浮现、生平淡入
- F372–F416：时间轴 4 节点错峰落下（每 6 帧）；相机缓慢下推
- F410–F470：特写记忆档案（约 55% 画面）：点击「＋ 记录一段记忆」→ 记忆逐字写入 → 计数「记忆 12→13」跳动
- F462–F500：交接——记忆卡缩小右滑，带出聊天面板（Content/Position 保持）
- F496–F556：对话特写（约 60% 画面）：顶部「基于 TA 的资料推测」角标固定；用户气泡逐字「最近工作好累，要是以前……」→ 发送
- F548–F570：三点输入指示 → AI 气泡「爷爷大概会先问你有没有好好吃饭。」
- F566–F600：错峰联动——evidence 记忆引用卡滑入（引用 F410 的记忆）、追问气泡浮现、左侧记忆卡高亮脉冲
- F600–F640：结果停留阅读；相机缓慢横移向祭堂

### S3 F628–F800｜祭堂点灯 → 记录上墙（能力扩展 + 系统联动）
- F628–F668：交接——对话头像 🕊️ 变形为烛台 → 祭品栏推入特写（鲜花/蜡烛/清香/糕点 + 免费标签）
- F660–F690：光标选中「蜡烛」（选中环亮起）→ 点击「点亮」
- F684–F726：错峰联动（4–6 帧间隔）：烛火燃起、光晕扩散、祭品计数变化、背景暖度提升
- F720–F770：祭奠记录错峰上墙「李** 点亮了蜡烛」「王** 献上了一束鲜花」「张** 上了一炷清香」；墙计数 1,024→1,027
- F766–F800：烛火特写放大至约 40% 画面，成为最终大运动起点

### S4 F790–F900｜拉远收束：万家灯火 → 品牌
- F790–F856：**大运动③** 烛火特写持续大拉远 → 缩小为墓园中一点暖光；全景重建，10 处烛光逐一点亮；前/中/远景三层视差
- F846–F884：「思念有处安放」字距展开浮现 → 「彼岸 · 线上纪念馆」淡入
- F884–F900：烛光继续轻微闪烁、萤火虫漂移——不静止成海报

## 4. Motion Audit（关闭背景运动后逐段自查）

| 段落 | 用户做了什么 | 系统响应 | 结果 | 下一动作何时开始 | 无意义等待 |
|---|---|---|---|---|---|
| S0 | 点击建馆按钮 | 按钮按下、相机推入 | 进入向导 | 按钮未停稳向导已启动（F096<F104） | 无 |
| S1 | 打字/选择/下一步×2/生成 | 步骤切换、内容更新、花瓣生成 | 纪念馆生成 | 每步按钮按下前下一步骤条已预热 | 无 |
| S2 | 写记忆、发消息 | 计数 +1、三点指示、AI 回答+引用+追问 | 记忆→对话闭环建立 | 记忆卡未读完对话面板已进入（F496<F500） | 无 |
| S3 | 选蜡烛、点亮 | 烛火/光晕/计数/记录错峰 | 祭奠记录上墙 | 最后一条记录未停稳烛火特写已启动（F766<F770） | 无 |
| S4 | —（收束） | 烛光逐一点亮 | 品牌价值浮现 | 拉远中途文案已开始浮现（F846<F856） | 结尾保留烛光微动 |

- 全片无 fade-out/fade-in 切页；所有转场均有交接对象
- 装饰性背景（星空/萤火虫）不计入有效动画；有效产品变化约 **70 处**（打字 6 段、按钮按下 6 次、步骤切换 3 次、内容浮现/更新 20+、错峰联动 12+、计数跳动 4、转场大运动 3、交接对象 5 等）
- 缓动：snap(0.16,1,0.3,1) / pop(0.34,1.45,0.44,1) / press(0.5,0,0.75,0) / smooth(0.37,0,0.2,1) / soft(0.25,0.8,0.3,1) 五组非对称曲线按运动类型分配，无全局统一
