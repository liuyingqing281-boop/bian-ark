- 依据角色规范：Product Showreel Director & Motion Engineer
- 产物：`/[lang]/showreel` 路由（帧驱动、可拖帧审计）
- 素材原则：使用项目真实 UI 语言（墓园石碑 / 建馆向导 / 馆主页 / 记忆档案 / 缅怀对话 / 祭堂祭品 / 留言墙），人名全脱敏（「李**」），逝者「王秀兰」为虚构示例

## 0. 产品理解（先理解产品，再修改动画）

| 问题 | 答案 |
|---|---|
| 这是什么产品 | 彼岸纪念馆：为逝去的亲人、宠物、想念的人建一座线上纪念馆，可记录故事、留言、献花点灯、与"基于记忆档案"的缅怀对话 |
| 谁会使用 | 异地/海外中青年悼亲者（主）、中老年高频悼念者、家族组织者 |
| 用户最核心的问题 | 无法到场祭扫，思念无处安放；现有产品诱导付费、阴森、不真实 |
| 最重要的 3–6 个功能 | ① 3 步建馆向导 ② 记忆档案（生平/相册/时间轴）③ 缅怀对话（带「基于 TA 的资料推测」诚实角标+记忆引用）④ 献花点灯祭堂 ⑤ 留言墙/悄悄话 ⑥ 公共墓园 |
| 完整价值路径 | 进入 → 建馆 → 记录记忆 → 想念时说话/对话 → 献花点灯 → 亲友共祭 → 思念有处安放 |
| 30s 最值得展示 | 建馆向导、馆生成、记忆→对话闭环、点灯联动 |
| 辅助不占主镜头 | 年卡/会员、后台审核、族谱导出、适老模式 |
| 最值得被记住的结果 | 一座有照片、有故事、能说话、能点灯的馆——"思念有处安放" |

## 1. 产品内容链

```
进入公共墓园（思念的现场）
↓ 点击「＋ 为 TA 建一座馆」
3 步建馆向导：TA 是谁 → TA 的故事 → 确认生成
↓ 系统生成纪念馆
馆主页：头像 / 生平 / 时间轴逐一建立
↓ 写入一段记忆（记忆档案 +1）
缅怀对话：提问 → AI 基于记忆回答 → 记忆引用卡 + 追问
↓ 进入祭堂
选择蜡烛 → 点亮 → 烛火燃起 → 祭奠记录错峰上墙（李**/王**/张**）
↓ 拉远
万家灯火的墓园全景 → 「思念有处安放 · 彼岸」
```
