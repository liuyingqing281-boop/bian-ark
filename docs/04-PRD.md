## 1. 产品概述

**一句话定位**：为无法到场的怀念者提供真实、庄重、透明的线上纪念馆（承 MRD §9）。

**目标用户**：P0 异地/海外中青年悼亲者（主）、P1 中老年高频悼念者（辅）、P2 家族组织者、P3 明星悼念者（MRD §4）。

**产品原则（红线，来自反面清单 BRD §2/MR-05）**：
1. 无虚拟币、无充值礼包、无排行榜/打榜
2. 无默认自动续费
3. 无未经审核的建馆（防"活人建馆"，样本13）
4. 全站用户名脱敏展示（与项目数据规范一致）

## 4. 功能需求详述

### FR-01 实名建馆与审核流（BR-01，P0，M1）

**目的**：满足《网络祭祀要求》实名认证要求（附录C），杜绝活人被建馆（样本13、24）。

**建馆向导（3 步）**：
1. **逝者信息**：姓名、性别、生卒年月（必填）；生平简介 100–300 字、封面照（建议微笑生活照，S13 建馆教程口径）选填。
2. **建馆人实名**：手机号实名 + 证件 OCR；选择与逝者关系（直系亲属/亲属/朋友/其他）。
3. **凭证提交**（按关系分级）：
   - 直系亲属：死亡证明/火化证/墓位证/医院离逝证明 任一，或讣告链接 + 承诺书
   - 非直系：上述凭证 + 馆主知情选项（可后补）
   - 同名公众人物：**禁止用户自建**，仅平台官方创建（防"烈士称号"类滥用，样本25）

**审核状态机**：`草稿 → 提交 → 机审（即时：敏感词/重名/在世名人库拦截）→ 人审（SLO 24h）→ 已上架 / 驳回（可申诉一次）`；举报触发 `先下架 → 复核`。

**边界与异常**：
- 逝者与建馆人同姓且生卒年明显在世 → 机审拦截并转人审
- 驳回理由必须具体到凭证类型；申诉通道 7×24
- 凭证文件加密存储、审核员不可导出（NFR-03）

**验收标准**：① 机审 <3s 出结果；② 人审 95% 在 24h 内完成；③ 任何状态变更留审计日志；④ 无凭证馆无法进入公开可见状态。

### FR-02 纪念馆基础空间（BR-02，P0，M1）

| 模块 | 规格 |
|---|---|
| 生平页 | 富文本 + 时间轴视图；馆主可编辑版本历史 |
| 纪念相册 | 免费容量 100 张照片 / 10 分钟视频 [设计目标]；年卡扩容（FR-06）；照片支持"生卒年场景"分组 |
| 留言墙 | 访客留言需登录；**展示名一律脱敏**（「李**」格式，同共享上下文数据规范）；馆主可精选/删除/关闭留言；留言支持"悄悄话"模式（仅馆主可见——样本09"还能说些悄悄话"） |
| 祭堂 | 基础祭品免费：鲜花、蜡烛、清香、糕点（4 类，无付费门槛——获客基准 0 元，BRD §2）；祭扫动作生成动态记录（"用户A 于清明献花"） |
| 悼文 | 馆主与授权亲友可撰写长悼文（对应"九年写悼文"行为，样本04） |

**验收标准**：建馆→首次祭扫/留言路径 ≤3 次点击；留言脱敏率 100%。

### FR-02b 馆内多人合馆「长明灯阵」（BR-02，P1，M4）

**目的**：支持一馆纪念多位逝者（1~6 人，夫妻合祀/父母同堂场景）。排布方案为**场景化灯阵**——不做卡片目录：每位逝者 = 共享夜空场景中的一盏灯，灯位表达关系（夫妻相邻、长辈居中略高），馆主可拖拽摆位。

**结构三层**：场景层（灯阵 + 名牌 + 独立明灭状态）→ 抽屉层（点击灯 400–700ms 聚焦，抽屉内展示该人物生平/相册/留言/供奉，顶部人物条一键切换）→ 馆级公共层（群像名单 + 全馆留言墙可按人筛选 +「为全家点灯」合祭）。

**关键规则**：
- 人数上限 6 人，超出引导至家族祠堂（FR-07）；单人馆为 N=1 特例，旧馆表现与 URL 不变
- 交互模型与组件全部复用墓园页规格（聚焦/抽屉三态/双主操作/时序档位）
- 数据：`halls 1—N memorials`（memorials 明确为"馆内人物"），归属与审核、脱敏、可见性在馆级统一
- 主题皮肤：长明灯阵（默认）/ 祠堂牌位墙（备选，随 M4 评估）；灯样式归入 FR-06 装饰主题 SKU
- 红线：无访问量展示、无热度排序

**详细规格**：`docs/13-馆内多人合馆（长明灯阵）展示方案.md`（2026-08-23 用户拍板方向）。

**验收标准**：见 13 号方案文档 §9（存量馆视觉基线一致、聚焦动画合规、合祭归属正确、摆位持久化等 7 条）。

### FR-03 支付与明码标价（BR-03，P0，M2）

- 全站仅人民币直付，**无任何中介币**；价格页集中公示所有 SKU（一口价 9.9/19.9/39.9/99 元 + 年卡 88 元，BRD §2 定价）
- 支付渠道：微信支付/支付宝；退款规则公示（未使用增值项 7 天无理由）
- 订单页展示价格构成；无组合促销、无倒计时逼单
- **验收标准**：全站搜索不到"币/礼包/排行"类 SKU；退款入口 2 次点击可达；支付合规资质就绪后才开放（M0 依赖）。

### FR-04 隐私保护与脱敏（BR-04，P0，M1）

- 馆访问权限三级：`公开 / 仅链接 / 私密（指定人）`；默认"仅链接"
- 用户名全站脱敏展示；留言者可选完全匿名（「用户A/B」递增代号）
- 馆主可一键关闭"访问量"公开展示（璐璐案中访问量公开加剧伤害，样本13）
- 个人信息最小化收集；凭证与证件号加密存储
- **验收标准**：任意公开页面不出现完整手机号/证件号/真名用户名；权限切换即时生效。

### FR-05 分享与亲友协作（BR-05，P0，M1）

- 分享卡片（含馆封面 + 一句话）→ 微信/朋友圈/复制链接；链接可设有效期
- 被分享亲友登录后可留言、献祭、申请成为协作管理员（馆主审批）
- 协作管理员可传照片、写悼文，不可改权限/删馆
- **验收标准**：分享落地页免注册可浏览（留言再登录）；协作邀请 24h 未响应自动过期。

### FR-06 年卡与单点增值（BR-06，P1，M2）

- "彼岸年卡" 88 元/年：**开关式订阅**——支付页默认不勾选自动续费；开启者到期前 7 天站内+短信提醒，随时一键关闭
- 单点 SKU：高级装饰主题（9.9–39.9）、相册视频扩容（19.9–99）、单人悼念空间升级（99）；价格长期公示，无节日涨价（反面对标样本18"清明节了价格比平时高"）
- 到期处理：增值内容只读不删除，续费后恢复
- **验收标准**：默认支付不含任何自动续费勾选；关闭续费 ≤2 次点击；到期前提醒触达率 ≥95%。

### FR-07 家族祠堂（BR-07，P1，M4）

- 多逝者馆聚合空间 + 族谱树（代际关系可视化）；多人管理（馆主互邀）
- 家族祠堂扩容 99 元/次 [BRD §2]；基础含 3 馆位
- 族谱信息仅家族内可见；支持导出 PDF 族谱
- **验收标准**：≥3 馆聚合流程 ≤10 分钟；族谱树支持三代关系渲染。

### FR-08 庄重调性规范（BR-08，P0，M1）

- 视觉基调：暖色低饱和、留白充分；**禁用**：阴森背景乐、闪烁动效、恐怖元素（S11 反证行业阴森感问题）
- 祭扫动效克制（烛光缓动、花瓣飘落二选一）；文案规范：用"缅怀/纪念/追思"，禁用营销话术（"限时""特惠"不得出现在祭堂场景）
- 适老模式：字号放大 1.5 倍、流程简化、高对比度（P1 细分低门槛诉求，MRD §4）
- **验收标准**：调性检查清单纳入发版验收；适老模式一键切换全站生效。

### FR-09 明星/事件纪念馆（BR-09，P1，M4）

- 仅平台官方创建与运营（用户可提名投票）；明星馆内献祭/留言功能与普通馆一致
- 提名需资质材料（公开报道/官方讣告）；烈士、公众人物称号使用规范前置审查（样本25 整改教训）
- 定位：获客入口（MRD §9）——明星馆内容可被站外分享，落地页引导"为亲人建馆"
- **验收标准**：用户无法自助创建公众人物馆；每馆带举报入口。

### FR-10 运营日历（BR-10，P1，M3 起）

- 节点：清明（4 月）、中元（农历七月十五）、冬至、寒衣节 + **用户自设纪念日**（逝者生日/忌日）
- 纪念日提醒：站内 + 可选短信，提前 3 天，频率用户可控
- 专题页聚合"代客祭扫暂不提供"的替代方案内容（庄重的线上仪式引导——殡仪馆长"提供群众能接受的替代方案"，样本30）
- **验收标准**：提醒可一键关闭全站；专题页无付费诱导元素。

### FR-11 投诉/举报/客服（BR-11，P0，M1）

- 入口：全站页脚 + 馆页悬浮，2 次点击可达
- 举报类型：冒名建馆（优先级最高）/内容不当/收费问题/隐私泄露；**冒名举报触发"先下架后复核"**（BRD §6）
- 客服 SLO：首响 2h（8:00–22:00）、一般工单 24h、监管相关工单升级直通负责人
- **验收标准**：BRD §7 红线可量化统计（客诉 24h 响应率 100%、自动扣费投诉 0）。

### FR-12 数据看板（BR-12，P1，M1 最小版）

**WAR 精确定义**（北极星，BRD §7）：自然周内以下埋点事件的总去重次数：
`留言(含悄悄话)、悼文发布、祭扫动作、照片/视频上传、分享点击、族谱编辑`

| 指标组 | 指标 |
|---|---|
| 获客 | 新建馆数、明星馆引流建馆占比、分享带来的注册占比 |
| 激活 | 建馆 7 日内首次祭扫/留言率（目标 ≥60%，BRD §7） |
| 留存 | 30 日 WAR 留存、悼文书写率 |
| 商业 | 付费转化率（目标 3–5%）、年卡开关续费率 |
| 红线仪表盘 | 冒名事故、监管点名、客诉 SLO、自动扣费投诉（任何一项亮红即发版阻断） |

**验收标准**：红线仪表盘实时可查；WAR 口径变更需留版本记录。

## 5. 核心用户流程

**流程 A：异地子女建馆（P0 主路径）**
注册 → 实名 → 建馆向导 3 步（含凭证）→ 机审即时/人审 24h → 上架通知 → 首次祭扫 → 分享给母亲那边亲戚 → 亲戚留言献祭 →（转化）装饰/年卡

**流程 B：中老年日常悼念（P1 路径，适老模式）**
子女代建/自建 → 每日打开馆 → 写悄悄话/留言 → 听背景音乐 → 纪念日收到提醒

**流程 C：举报冒名（红线流程）**
任意访客 → 馆页"举报" → 选"冒名建馆" → 馆即时转入"复核中"（不可访问）→ 审核 48h 内结论 → 通知双方 → 申诉通道

**流程 D：付费（透明流程）**
明码标价页 → SKU 明细 → 支付（无默认续费勾选）→ 凭证与发票 → 退款入口常驻个人中心
